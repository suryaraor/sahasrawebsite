# Sahasra Rayarao - Personal Website

A beautiful, modern personal website showcasing Sahasra's journey as an artist and aspiring software engineer.

## About Sahasra

Sahasra Rayarao is a passionate 10th-grade student at Blue Valley West High School in Overland Park, Kansas. She combines her love for visual arts with her growing expertise in technology, including:

- **Artistic Passion**: Creative expression through various visual mediums
- **Technical Skills**: Data Science and Java programming
- **Current Learning**: Software Engineering and Artificial Intelligence
- **Future Goals**: Innovating at the intersection of art and technology

## Website Features

- **Responsive Design**: Optimized for all devices (desktop, tablet, mobile)
- **Modern UI/UX**: Clean, professional design with smooth animations
- **Interactive Elements**: Hover effects, scroll animations, and dynamic content
- **Sections Include**:
  - Hero section with animated introduction
  - About section with personal story and achievements
  - Skills showcase highlighting technical and artistic abilities
  - Projects section displaying current interests and work
  - Contact information for networking and collaboration

## Technologies Used

- **HTML5**: Semantic markup structure
- **CSS3**: Modern styling with flexbox, grid, and animations
- **JavaScript**: Interactive features and smooth scrolling
- **Font Awesome**: Professional icons
- **Google Fonts**: Typography (Poppins font family)

## Getting Started

1. Clone or download the repository
2. Open `index.html` in a web browser
3. No additional setup required - it's a static website!

## Customization

The website is designed to be easily customizable:
- Update personal information in the HTML content
- Modify colors by changing CSS custom properties
- Add new sections by following the existing structure
- Replace placeholder project information with actual projects
